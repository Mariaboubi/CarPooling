# ΠΧ2. Επιλογη Ιδιοτητας

**Γενικός actor**: Χρήστης
**Περιγραφή**: Κάθε φορά που ο χρήστης εισέρχεται στην εφαρμογή, του δίνεται η δυνατότητα να επιλέξει την ιδιότητά του ως οδηγός ή υποψήφιος συνεπιβάτης.
**Προϋποθέσεις**: Ο χρήστης έχει εκτελέσει με επιτυχία την περίπτωση χρήσης "Σύνδεση στο λογαριασμό"
  
## Βασική Ροή

1. Ο χρήστης εισέρχεται στην εφαρμογή.
2. Επιλέγει αν είναι οδηγός ή υποψήφιος συνεπιβάτης.
3. Εφόσον επιλέξει οδηγός, μεταφέρεται στις λειτουργίες που αφορούν τον οδηγό. Εάν επιλέξει υποψήφιος συνεπιβάτης, μεταφέρεται στις λειτουργίες που αφορούν τον συνεπιβάτη.

## Εναλλακτικές ροές

*2α. Επιλογή ιδιότητας οδηγού χωρίς τα απαραίτητα στοιχεία*
     1. Ο χρήστης θα πρέπει να συμπληρώσει τα απαραίτητα στοιχεία.
          - Πηγαίνει στο βήμα 3 της βασικής ροής
          - Τερματίζει η περίπτωση χρήστη
