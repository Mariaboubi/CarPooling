# ΠΧ9. Στατιστικά στοιχεία

**Γενικός actor**: Χρήστης

**Δευτερεύοντες Actors** : Διαχειριστής Συστήματος

**Περιγραφή**: Ο χρήστης έχει πρόσβαση σε στατιστικά στοιχεία σχετικά με τη χρήση της εφαρμογής και τις διαδρομές.

## Βασική Ροή

1. Ο χρήστης επιλέγει την κατηγορία "Στατιστικά".
2. Εμφανίζονται γενικά στατιστικά στοιχεία, όπως μηνιαία έσοδα της εταιρείας, μέση πληρότητα
3. Εμφανίζονται τα προσωπικά στατιστικά στοιχεία του κάθε χρήστη όπως αριθμός διαδρομών, μηνιαία εξοδα.
