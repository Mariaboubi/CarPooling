# ΠΧ7. Εκτέλεση διαδρομής και κατανομή πληρωμών

**Πρωτεύων Actor**: Οδηγός
**Ενδιαφερόμενοι**
**Οδηγός**: Θέλει να εκτελεί δρομολόγια
**Υποψήφιος συνεπιβάτης**: Θα συμμετέχει στην διαδρομή μαζί με τον οδηγό
**Προϋποθέσεις**: Ο οδηγός θα έχει εκτελέσει με επιτυχία την περίπτωση χρήσης "Σύνδεση στο λογαριασμό" και τον " Προσδιορισμός στοιχείων διαδρομής και επιλογή επιβατών"

## Βασική Ροή

1. Παραλαβή συνεπιβατών από τα προκαθαρισμένα σημεία
2. Εκτέλεση διαδρομης
3. Άφιξη στον προορισμό
4. Υπολογισμός κόστους που αναλογεί στον κάθε συνεπιβάτη
5. Εισπραξη ποσού

## Εναλλακτικές Ροές
