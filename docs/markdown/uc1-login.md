# ΠΧ1. Σύνδεση στο λογαριασμό

**Γενικός actor**: Χρήστης

**Περιγραφή**: Ο χρήστης εισέρχεται στην εφαρμογή μέσω του λογαριασμού του.

## Βασική Ροή

1. O χρήστης εισέρχεται στην εφαρμογή.
2. Επιλέγει είσοδο (Sign in) ή εγγραφή (Sign up) αν δεν είναι εγγεγραμμένος.
3. Στη περίπτωση επιλογής της εγγραφής ο χρήστης θα πρέπει να συμπληρώσει τα απαραίτητα στοιχεία. Τέλος δημιουργεί ένα username και ένα password ώστε να γίνεται η ταυτοποίησή του κάθε φορά που μπαίνει στην εφαρμογή.
4. Καταχωρεί το όνομα χρήστη και τον κωδικό πρόσβασης.
5. Εάν τα στοιχεία είναι σωστά, εισέρχεται στον προσωπικό του λογαριασμό.

## Εναλλακτικές ροές

2α. Λάθος Στοιχεία Εισόδου:

- Ο χρήστης καταχωρεί λανθασμένα στοιχεία εισόδου. Στη συνέχεια, εμφανίζεται μήνυμα λάθους και του ζητείται να ξαναπροσπαθήσει.

2β. Ξεχασμένος Κωδικός Πρόσβασης:

- Ο χρήστης επιλέγει την επιλογή "Ξέχασα τον κωδικό μου" και ακολουθεί τη διαδικασία ανάκτησης κωδικού.
