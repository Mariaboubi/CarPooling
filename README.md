# Car pooling - Επισκόπηση Έργου

Το **CarPooling** είναι ένα πολυεπίπεδο έργο λογισμικού (σε Java) που υλοποιεί ένα σύστημα κοινοχρησίας/συνεπιβατισμού. Η ανάπτυξη οργανώνεται σε τέσσερα παραδοτέα (στάδια):
(Σε κάθε στάδιο γινόταν αξιολόγηση απο τον καθηγητή και προχωρουσαμε στις απαιτούμενες διορθώσεις)

### R1 – Απαιτήσεις / Μοντελοποίηση Περιπτώσεων Χρήσης
Συλλογή και καταγραφή βασικών λειτουργικών και μη λειτουργικών απαιτήσεων του συστήματος, δημιουργία διαγραμμάτων περιπτώσεων χρήσης, ορισμός χρηστών (actors) και ορίων του συστήματος.

### R2 – Ανάλυση Συστήματος
Αναλυτικότερη περιγραφή απαιτήσεων, επέκταση περιπτώσεων χρήσης, μοντελοποίηση συμπεριφορών (π.χ. διαγράμματα ακολουθίας, κλάσεων) και διαμόρφωση της προδιαγραφής του συστήματος.

### R3 – Σχεδίαση & Υλοποίηση Λογικής
Σχεδίαση αρχιτεκτονικής και βασικών κλάσεων/σχέσεων, ορισμός διεπαφών και αλγορίθμων, unit tests καθώς και υλοποίηση του πυρήνα της επιχειρησιακής λογικής.

### R4 – Λειτουργικό Παραδοτέο
Πλήρως λειτουργική εκδοχή του συστήματος CarPooling, με ενσωμάτωση όλων των υποσυστημάτων, λειτουργική ροή από άκρο σε άκρο, δοκιμές και προετοιμασία για χρήση. Η εφαρμογή υλοποιειτε σε Android Stusio, ο τελικός κώδικας βρίσκεται στο branch `working_version`

# CarPooling - Project Overview (English)

CarPooling is a multi-stage software project (in Java) that implements a ride-sharing / carpooling system. The development is structured into four deliverables (stages):
(At each stage, the project was evaluated by the professor, and we implemented the required corrections before moving on to the next stage)

### R1 – Requirements / Use Case Modeling
Gathering and documenting high-level functional and non-functional requirements, creating use case diagrams, defining actors and system boundaries.

### R2 – System Analysis
Expanding requirements, refining use cases, modeling system behavior (e.g., sequence and class diagrams), and producing a detailed system specification.

### R3 – Design & Logical Implementation
Designing the system architecture and key classes/relationships, defining interfaces and algorithms, unit tests and implementing the core business logic.

### R4 – Functional Delivery
A fully working version of the CarPooling system, integrating all subsystems, supporting end-to-end functionality, including testing and deployment readiness. The application is implemented in Android Studio, and the final code can be found in the working_version branch.
